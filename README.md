# Замер комнаты

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

Пошаговый мастер для самостоятельного замера комнаты под расчёт натяжного
потолка: длины стен, внутренние/внешние углы, диагонали для контроля
прямоугольности, точки под светильники и трубы. По ходу замера строится
живая SVG-схема комнаты, в конце — периметр и площадь.

Открытый проект (MIT), сделан для мобильного веба (одна колонка, шаг за
шагом, крупный ввод цифр).

## Возможности

- Пошаговый ввод стен по часовой стрелке с автоматическим определением,
  когда комната замкнулась
- Выбор внутреннего/внешнего угла на каждом повороте
- Опциональный замер диагоналей (появляется от 4 стен) для проверки
  прямоугольности комнаты
- Расстановка светильников/труб/прочих точек на плане с перетаскиванием
- Итоговая схема, периметр и площадь; шаринг результата через `navigator.share`
  или буфер обмена
- Живой SVG-предпросмотр на каждом шаге

## Технологии

- [Vue 3](https://vuejs.org/) (Composition API, `<script setup>`)
- [Pinia](https://pinia.vuejs.org/) — состояние замера и SVG-рендеринг
- [Vite](https://vitejs.dev/)
- TypeScript (проверка типов через `vue-tsc`; исходники на JS/Vue SFC)
- ESLint (flat config) + Prettier

## Быстрый старт

Требуется Node.js 20+.

```bash
npm install
npm run dev
```

Приложение будет доступно на `http://localhost:3000`.

## Скрипты

| Команда                | Назначение                            |
| ---------------------- | ------------------------------------- |
| `npm run dev`          | Дев-сервер с горячей перезагрузкой    |
| `npm run build`        | Production-сборка в `dist/`           |
| `npm run preview`      | Локальный просмотр production-сборки  |
| `npm run lint`         | Проверка ESLint                       |
| `npm run lint:fix`     | Проверка ESLint с автофиксом          |
| `npm run format`       | Форматирование Prettier               |
| `npm run format:check` | Проверка форматирования без изменений |
| `npm run typecheck`    | Проверка типов через `vue-tsc`        |

Перед коммитом стоит прогнать `lint`, `format:check` и `typecheck` — CI-конфига
в репозитории пока нет, это на совести контрибьютора.


## Участие в проекте

Issues и merge request'ы приветствуются. Перед отправкой MR:

1. Убедитесь, что `npm run lint`, `npm run format:check` и `npm run typecheck`
   проходят без ошибок
2. Держите изменения сфокусированными — один MR на одну задачу
3. Для больших изменений сначала откройте issue, чтобы обсудить подход
